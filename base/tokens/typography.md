# Typography

## Font Stack
```
--font-family: 'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif;
--font-mono: 'JetBrains Mono', 'Consolas', monospace;
```

## Scale
| Token | Size | Weight | Usage |
|---|---|---|---|
| `--text-xs` | 11px | 400-500 | Meta labels, overline |
| `--text-sm` | 13px | 400 | Table cells, helper text |
| `--text-base` | 14px | 400 | Body text, inputs |
| `--text-md` | 15px | 500 | Section headings |
| `--text-lg` | 18px | 600 | Page titles, modal titles |
| `--text-xl` | 24px | 700 | Hero metrics |
| `--text-2xl` | 28px | 700 | Display text |
