# Colors

## Primary
| Token | Value | Usage |
|---|---|---|
| `--color-primary` | `#1A73E8` | Primary actions, links, focus rings |
| `--color-primary-hover` | `#1557B0` | Hover state |
| `--color-primary-light` | `#E8F0FE` | Selected backgrounds, highlights |
