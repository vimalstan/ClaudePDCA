# Frontend UI

Specialist skill for building React pages and components. Loaded alongside lifecycle skills when UI work is detected.

## When to Use

Files touched include `components/`, `pages/`, `*.css`, `*.tsx` with JSX.

## Guidelines

- Use project design system tokens (base or project-overridden)
- Functional components with TypeScript
- Form validation with react-hook-form + Zod schemas
- Accessible: focus indicators, aria labels, keyboard navigation
- Responsive: mobile-first, use design system breakpoints
- Theme-aware: support light/dark via design tokens
- Work on direct branch (not worktree) for Vite live preview
