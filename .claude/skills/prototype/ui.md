# UI Prototype

Interactive HTML mockup to validate user flows before building.

## Process

1. Read spec.md for functional requirements and acceptance criteria
2. Build a single-file HTML/CSS/JS prototype
3. Focus on flow and structure, not pixel perfection
4. Include all major user interactions (clicks, forms, navigation)
5. Save to `.claude/prototypes/{task-id}-ui.html`
6. Present to user for feedback
7. Update spec/plan based on feedback

## What It Is NOT

- Not production code — no framework, no build step
- Not a design comp — layout and flow only
- Not complete — happy path + key error states only
